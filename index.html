Upload the Print View PDF you already download from BJTS (or paste the Job Summary page), pick a coat and day, check over the runs, and download a filled copy of your Spraysheet — Length, Area, Tank Dip, Litres, Spray Temp and Target Rate already in, formulas intact.

1 Get the BJTS report in

Upload the "Print View" PDF you already download from BJTS's Job Summary page — it's the easiest option, and it carries a couple of things the copy-paste doesn't (a real time for each run, and the coat number tagged on every row). If you'd rather, you can still paste the page's text instead.

Or paste the Job Summary page text instead

Open the job on BJTS's Job Summary page, select everything on the page (the job details, both coat blocks, and the run tables — Ctrl/Cmd+A works fine) and paste it below. Truncated cells like 11/09/20... or 38.4700... are fine, the fields this tool needs aren't cut off.

2 Job, coat & day

BJTS numbers these Coat 1 / Coat 2 — that's what picking a tab below means. Which one is actually the top or bottom coat on this job is your call; the tool doesn't guess it.

3 Header details

Pulled from BJTS where possible. Anything BJTS doesn't track (kerosene/AGO/adhesion rates, operator, weather, docket, site no.) needs a manual line — same as filling the sheet by hand.

4 Runs for this coat & day(s)

Runs are ordered by Run Number — the sequence BJTS logged them in, which is the order he actually sprayed, since this report doesn't carry a time-of-day field. RP, Direction, Chip Grade and Source aren't in BJTS's data — add them per row, or use the "apply to all" boxes below for Chip Grade/Source if one applies to the whole day.

* Width and Actual Rate are calculated by the Spraysheet's own formulas (Area÷Length and Litres÷Area) — shown here as a preview only, not written to the file.

Actual spray rate = total bitumen ÷ final area. On a two-coat day, pick which grade's area is the final sealed area (defaults to the top coat, the last one sprayed). Only the final grade's area goes on the sheet, and it has the same Final grade dropdown, so you can change it in Excel later too.

Residual binder @ 15°C — NZTA P18 temperature correction. Goes into hidden columns U–X on the sheet, with EBC and density on its Inputs tab, not the printed layout.

Flags: hand-spray? means the run number jumped by more than one — a gap like that usually means a section was sprayed by hand and never logged to BJTS. new load? means this run's tank start volume doesn't match the previous run's finish volume — the tanker was probably topped up or swapped between these two runs. check manually means BJTS didn't record a real time or temperature for this run at all — it's grouped under "No time recorded" above rather than a real day, since this tool can't guess which day it belongs to. All three are guesses or gaps worth a quick look, not certainties — hover a pill for the details.

The Spraysheet now sizes itself to fit — every ticked row here gets a row on the sheet, plus 5 blank rows after them in case you need to add anything by hand. Each row also carries its real time (from the PDF) and any flag text in two extra columns, hidden by default — right-click the column headers in Excel and "Unhide" if you want to see them.

5 Get the filled Spraysheet

After it opens: press Ctrl+Alt+F9 (Windows Excel) once — Calculate Now on the Formulas tab does the same thing — to refresh Width, Application Rate and the totals. This is a one-off step any tool that writes values in in bulk needs; Excel does it for you on every edit after that.
