# Spraysheet Filler

Turns a BJTS (CTEK) Job Summary "Print View" PDF — or the pasted Job Summary page — into a filled Higgins BOP daily Spraysheet (.xlsx).

Everything runs in the browser: the PDF and any pasted text never leave your computer. The only things loaded from the internet are the PDF reader (pdf.js from cdnjs) and fonts.

Features: dynamic row count with 5 spare rows, per-grade areas on two-coat days, Final grade dropdown (Actual Spray Rate = Total Bitumen ÷ Final Area), and hidden NZTA P18 residual binder @ 15°C / payment tonnage columns (U–X).

Hosted with GitHub Pages: open `index.html`, or the Pages link for this repo.
